# Canon Policy

Canon is the accepted truth of the world and campaigns. Drafts, generated ideas, imported notes, and brainstorming are not canon until promoted into the main content folders.

## Canon Folders

Canon lives under `data/<WorldName>/`.

Recommended world sections:

- `History/`
- `Places/`
- `Factions/`
- `Organisations/`
- `Campaigns/`
- `People/`
- `Pantheon/`
- `Notes/`

## Draft And Import Folders

- `ideas/`
- `imports/`
- `generators/`

## Promotion Rules

- New content starts as an idea, import, generated draft, or `candidate` file under `data/<WorldName>/`.
- Canon changes should preserve contradictions as notes instead of silently deleting them.
- Major player decisions should create timeline events.
- Faction changes should update both the faction file and the relevant campaign state.
- Names, dates, places, and relationships should use stable IDs when possible.

## Canon Statuses

- `draft`
- `candidate`
- `canon`
- `retired`
- `contradicted`
