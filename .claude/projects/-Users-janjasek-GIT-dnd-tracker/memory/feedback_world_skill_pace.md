---
name: World skill — pacing and approach
description: How to run world-building sessions for this DND project
type: feedback
---

Lead with questions and information retrieval, not content generation. The user has a lot of unwritten lore in their head — the job is to surface it through targeted questions, not fill gaps with invented material. One topic at a time, 3-4 questions max per turn. Offer to write canon only after the user has confirmed the direction.

**Why:** The user explicitly said "I can only take so much" and "I have a lot of thoughts that were probably not written anywhere." Walls of generated content crowd out the user's own ideas.

**How to apply:** In every world-building turn: read existing files first, ask 2-4 focused questions, wait for answers before drafting anything into canon.
